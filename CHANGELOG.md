# Changelog

## 0.1.0

Initial release for dsh 0.2 (`>=0.2.0-rc.2`).

- Chrome DevTools MCP bridge over stdio through `@deepseek-ai/dsh-mcp-client`
  (`npx -y chrome-devtools-mcp@latest [extraFlags]`), tools under
  `mcp__<serverName>__*`.
- Settings → Plugins page generated by the harness from the plugin schema;
  `extraFlags` and `chromePath` are volatile — Settings edits relaunch the
  bridge and re-run the Chrome executable check without restarting dsh.
- Startup Chrome executable probe with per-platform stable-channel discovery;
  actionable "Chrome not found" classification pointing at the upstream
  configuration guide.
- Tool-failure and recovery surfacing through host logs; `DSH_CHROME_MCP_FLAGS`
  launch-environment override while the config holds the schema default.
- Designed as the dsh-0.2 successor of `@comecaramelos/dsh-chrome-mcp`
  (same functionality, minus the 0.1-only custom settings card, live-status
  base layer, and re-check button — 0.2 has no host→client status channel).
